🔌 ESP32 Sensor Mini Projects

A collection of simple and practical ESP32 sensor-based mini projects developed to learn sensor interfacing, GPIO control, analog/digital signals, and basic IoT concepts.

This repository contains multiple small projects, with each sensor demonstrated through a separate practical application.

🎯 Project Goal

The main goal of this repository is to explore different sensors individually and understand how they work with the ESP32 development board.

Instead of building one large project, each sensor is used to create a small and easy-to-understand project.

Learning Areas

- ESP32 GPIO
- Digital Sensors
- Analog Sensors
- Sensor Interfacing
- Arduino Programming
- Basic Automation
- Actuator Control
- Serial Monitor Debugging
- Practical Electronics
- IoT Fundamentals

🔊 Example – Sound Activated Light

The first mini project uses a sound sensor module with an ESP32.

Working Principle

Sound
  ↓
Sound Sensor
  ↓
ESP32
  ↓
Signal Processing
  ↓
LED

When sound is detected, the ESP32 reads the sensor signal and controls an LED.

Basic Components

- ESP32
- Sound Sensor Module
- LED
- Resistor
- Jumper Wires
- Breadboard
